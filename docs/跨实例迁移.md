# 跨实例家庭数据迁移

把一个家庭（条目、人物、媒体、故事、分享链接、审计日志……全部）从一个运行实例搬到另一个实例。典型场景：换机器、把数据从云托管搬回家里、给亲友复制一份档案。

## 它保证什么

| 能力 | 做法 |
| --- | --- |
| 家庭数据全量导出 | 15 张表按家庭范围导出成 JSONL，媒体原件 + 派生文件（缩略图/波形/转码）按内容寻址整体打包，清单记录每个文件的大小与 sha256 |
| 目标端校验 | 导入前校验包完整性（哈希/行数/媒体）、目标库迁移版本、台账表、存储可写与磁盘空间、包内外键自洽性；任一不过即中止 |
| 标识重映射 | 源端所有 cuid 在目标端重新生成，新旧 ID 对应关系全部记入 `migration_records` 台账；外键、版本快照 JSON、审计 diff、媒体存储路径一并改写 |
| 幂等重放 | 同一迁移包重复导入不产生重复数据：每行先查台账，已导入则跳过并复用旧映射；行级事务保证「数据 + 台账」同生共死 |
| 失败可回滚 | 导入前对目标家庭存储子树拍快照；回滚按台账逆序删除迁入数据、还原被覆盖的媒体文件，合并到目标端的既有账号与家庭一律保留 |

## 命令

```bash
# 源端：DATABASE_URL / STORAGE_ROOT；目标端：TARGET_DATABASE_URL / TARGET_STORAGE_ROOT

pnpm migrate:export --family <家庭ID> --out data/exports/migration
pnpm migrate:validate --bundle <迁移包目录>      # 只校验，不写数据
pnpm migrate:import   --bundle <迁移包目录>      # 校验 + 导入 + 导入后复核
pnpm migrate:import   --bundle <迁移包目录> --dry-run
pnpm migrate:verify   --bundle <...> --run <批次ID>
pnpm migrate:rollback --run <批次ID> --yes
pnpm migrate:list
```

跨实例时在命令前显式指定两端连接：

```bash
DATABASE_URL=postgres://...源端 \
STORAGE_ROOT=/srv/heirloom/data/uploads \
TARGET_DATABASE_URL=postgres://...目标端 \
TARGET_STORAGE_ROOT=/mnt/new/data/uploads \
pnpm migrate:import --bundle data/exports/migration/migration-xxxx
```

也可以把数据并入目标端一个**已存在的家庭**（家庭行本身不迁移，回滚时保留家庭）：

```bash
pnpm migrate:import --bundle <...> --target-family <目标家庭ID>
```

## 迁移包结构

```
migration-<bundleId>-<时间>/
├── manifest.json     # bundleId、来源家庭/迁移版本、每张表行数、每个文件 sha256
├── README.txt
├── tables/*.jsonl    # 15 个实体各一个文件，一行一条（Date/BigInt/Decimal 带类型标签）
└── storage/
    └── families/<源家庭ID>/objects/..   # 内容寻址原件
        └── families/<源家庭ID>/derived/..  # 缩略图、波形、转码
```

目标端只相信 `manifest.json` 里的哈希：表文件或媒体被改动一个字节，校验即失败、导入中止。

## 账号怎么处理

- 源端家庭成员按成员关系带入；目标端**已存在同邮箱账号时合并**（挂到既有账号上，不覆盖密码与资料），并在导入日志中标注。
- 邀请码、分享链接存的是哈希值，迁移后**原链接/邀请码继续可用**。
- 回滚时，合并到目标端的既有账号绝不删除。

## 失败与重放

- 导入中断（断电、磁盘满、媒体落盘缺失）会在 `migration_runs` 留下 `failed` 批次，但已提交的行都有台账。
- 修复问题后**原样重跑同一命令**即可：已导入的行跳过，缺失的媒体重新复制，最终以一次通过的导入后复核为准。
- 每次重放复用最早批次的迁移前快照，因此无论重跑多少次，回滚都回到「第一次迁移之前」。

## 回滚语义

- 新建家庭迁移：回滚删除迁入的全部行与空家庭，删除迁入的媒体文件，目标端回到迁移前。
- `--target-family` 并入既有家庭：回滚删除迁入数据、**还原被覆盖的媒体文件内容**，但保留家庭本身和它原有的成员/条目/账号。
- 回滚自身幂等；台账清空后该迁移包可作为全新包再次导入。
